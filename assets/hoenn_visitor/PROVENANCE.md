# Hoenn visitor visual set, revision 2

Same original character in four presentations: native Gen-1, illustrated HD, voxel-HD, and Cobble Human. Identity: short brown bob, ivory tied bandana, rust-red travel top, navy shorts, cream socks, brown shoes and honey satchel.

The native Gen-1 and the two enhanced raster masters were made with the built-in Imagegen tool. Native reference: the local Gen-1 `girl.png` sheet, enlarged only to make its original pixel grid readable to the tool. HD style/layout reference: the existing project Mira atlas. Voxel reference: this visitor's HD output. Raster packing uses one common alpha union per style, removes disconnected background flecks, and retains native transparent fallback strips. Native master, conversion and provenance are shipped in KASC's `assets/sources/characters/hoenn_visitor`.

Cobble Human is an actual articulated cuboid rig authored on the existing local Ascendant Cobble Characters `original_v3.py` / `roster_source.py` system. The necessary rig functions and `cube_baker.lua` are copied under `tools/hoenn_visitor/inputs` with their source comments. The new identity, palette, bandana and satchel are defined by `build_model.py`. It exports 15 bones, 71 cuboids, Bedrock-format geometry, palette texture, idle/walk/blink animations and a poser. The LÖVE baker produces four directions of idle, twelve walking phases and four blink phases; its three-pose preview is packed as VASC's conventional 3x4 atlas. Raw model files are supplied as editable sources; Minecraft/Cobblemon import has not been tested.

Keep top/bottom and left/right frame positions exactly matching input. No gradients, no antialias, no glow, no 3D, no modern pixelart, no cute huge hat. Same woman in all six views. This is the actual in-game native sprite sheet, not concept art.
