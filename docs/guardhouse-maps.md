# Guardhouse maps

GateMaps decorates only native Gen 1 gate panoramas. Painted windows remain flat and provide InteriorLights daylight/night portals. Kanto uses the existing VASC regional map; Sevii uses the three original FireRed USA 1.0 regional charts. Asset hashes and extraction provenance are recorded in assets/maps/gate-atlas-sources.json. The chart viewport crops away the original Cancel button and outer margin.

The nearby prompt is English by default and German through SetupLocale. A opens a frozen-world map viewer; B dismisses it until the player leaves the nearby area. Sevii pages cycle with Left/Right. Map and save changes invalidate the frame. Native interactions run first, and no game inventory, flags, travel destinations or unlocks are modified. Classic rendering retains the original artwork and interactions.
